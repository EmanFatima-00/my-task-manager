A simple interactive Task Manager web app made with HTML, CSS and JavaScript.

Features:
- Add, Edit, Delete tasks
- Mark as complete / pending
- Search tasks
- Filter by All / Pending / Completed
- Priority (High, Medium, Low) and Due Date
- Local storage support - tasks stay after refresh
- Form validation and error handling
- Fully responsive for mobile and desktop

How to run:
1. Download or clone the repo
2. Open index.html with Live Server or any browser

Tech: HTML5, CSS3, Vanilla JavaScript
